# Проект "За любовь" - Telegram бот

Telegram-бот для проекта "За любовь" - платформа для продажи продуктов, управления подписками и работы с реферальной программой.

## Описание

Бот предоставляет пользователям доступ к:
- Подписке на платформу с доступом ко всем разделам
- Каталогу продуктов (игры, курсы, сервисные карты и т.д.)
- Образовательному контенту
- Продуктам стратегических партнеров
- Реферальной программе с многоуровневой системой выплат
- Информации о мероприятиях и городах

## Установка и запуск

### Требования

- Python 3.8+
- MySQL база данных
- Аккаунт YooKassa для приема платежей
- (Опционально) Google Drive API для резервного копирования

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка

1. Скопируйте переменные окружения или отредактируйте `config.py`:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
export YOOKASSA_SECRET_API="ваш_секретный_ключ"
export DB_CONNECTION_STRING="mysql+pymysql://user:password@host:port/database"
```

2. Настройте подключение к базе данных в `config.py` или через переменную окружения `DB_CONNECTION_STRING`

3. (Опционально) Настройте резервное копирование:
   - Создайте сервисный аккаунт в Google Cloud
   - Скачайте JSON-ключ
   - Укажите путь в `GOOGLE_SERVICE_ACCOUNT_FILE`
   - Укажите ID папки в Google Drive в `GDRIVE_FOLDER_ID`

### Запуск

**Основной бот:**
```bash
python bot.py
```

**Сервис проверки платежей (отдельно или через uvicorn):**
```bash
python checker.py
# или
uvicorn checker:app --host 0.0.0.0 --port 8000
```

## Основные функции

### Регистрация пользователей

При первом запуске `/start` пользователь проходит регистрацию:
1. Указание города
2. Подтверждение номера телефона
3. Получение бесплатной подписки на 30 дней

### Подписки

- Покупка подписки на месяц (333₽) или год (3333₽)
- Автоматическое продление подписки
- Уведомления за 3 дня, 1 день и после истечения срока

### Платежи

- Интеграция с YooKassa для приема платежей
- Автоматическая проверка статуса платежей
- Фискальные чеки для всех платежей

### Реферальная программа

- Многоуровневая система (до 20 линий)
- Автоматическое начисление бонусов при покупках рефералов
- Уровни партнерской программы (1-6)
- Перевод средств между пользователями

### Образовательный контент

- Каталог курсов с описаниями и медиа
- Автоматические выплаты партнерам-авторам курсов
- Уведомления о покупках

## Разделы бота

1. **О проекте** - информация о проекте "За любовь"
2. **Наши города** - список городов с контактами
3. **Подписка** - управление подпиской
4. **Медиа / Материалы** - ссылки на соцсети и презентации
5. **Наши мероприятия** - информация о мероприятиях
6. **Наши продукты** - каталог продуктов
7. **Образовательный контент** - каталог курсов
8. **Стратегические партнеры** - продукты партнеров
9. **Техническая поддержка** - обращение в поддержку
10. **Партнёрская программа** - управление реферальной программой

## Команды бота

- `/start` - главное меню и регистрация
- `/backup` - создание резервной копии БД (только для администратора)
- `/SlashCheckSubs` или `/check_subs` - ручная проверка подписок (для администратора)

## Технологии

- **Python 3.8+**
- **pyTelegramBotAPI** - работа с Telegram Bot API
- **SQLAlchemy** - ORM для работы с БД
- **YooKassa** - прием платежей
- **FastAPI** - сервис проверки платежей
- **MySQL** - база данных

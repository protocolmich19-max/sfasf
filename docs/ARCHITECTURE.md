# Архитектура проекта "За любовь"

Этот документ описывает архитектуру Telegram-бота проекта "За любовь" и принципы организации кода.

## Общая структура проекта

Проект представляет собой Telegram-бота на Python, который работает как платформа для продажи продуктов, управления подписками и работы с реферальной программой.

```
forlove/
├── bot.py                 # Точка входа, инициализация бота
├── checker.py             # Сервис проверки платежей (FastAPI)
├── config.py              # Конфигурация проекта
├── db/                    # Работа с базой данных
│   ├── models.py          # SQLAlchemy модели
│   ├── connect.py         # Подключение к БД
│   └── handlers.py        # Базовые операции с БД
├── handlers/              # Обработчики сообщений и callback'ов
│   ├── start.py           # Обработка команды /start
│   ├── callback.py        # Обработка inline кнопок
│   ├── subscription_checker.py  # Проверка подписок
│   └── db_backup.py       # Резервное копирование БД
├── services/              # Бизнес-логика
│   ├── payment_service.py      # Работа с платежами
│   ├── referral_service.py      # Реферальная система
│   └── subscription_service.py # Управление подписками
├── utils/                 # Вспомогательные функции
│   ├── referral.py        # Расчеты реферальных бонусов
│   ├── media.py           # Отправка медиа-файлов
│   └── text.py            # Работа с текстом
├── assets/                # Медиа-файлы проекта
└── docs/                  # Документация
```

## Основные компоненты

### 1. bot.py - Главный файл бота

**Назначение:** Инициализация бота, регистрация обработчиков, запуск фоновых задач.

**Основные функции:**
- Создание экземпляра TeleBot
- Регистрация обработчиков команд (`/start`, `/backup`)
- Регистрация обработчиков сообщений и callback'ов
- Запуск фоновых задач (проверка подписок, резервное копирование)

**Зависимости:**
- `handlers.start` - обработка команды /start
- `handlers.callback` - обработка inline кнопок
- `handlers.subscription_checker` - проверка подписок
- `handlers.db_backup` - резервное копирование

### 2. checker.py - Сервис проверки платежей

**Назначение:** Отдельный FastAPI сервис, который периодически проверяет статус платежей в YooKassa и обрабатывает успешные оплаты.

**Основные функции:**
- Получение списка платежей из YooKassa
- Проверка статуса оплаты
- Обработка успешных платежей:
  - Обновление `pay_metadatas.has_payed`
  - Создание записей в `payment_records`
  - Начисление реферальных бонусов
  - Обработка специальных продуктов (курсы, партнерские продукты)
  - Отправка уведомлений

**Особенности:**
- Работает в отдельном потоке
- Проверяет платежи каждые 5 минут
- Обрабатывает только необработанные платежи (`has_payed = False`)

### 3. config.py - Конфигурация

**Назначение:** Централизованное хранение всех настроек проекта.

**Содержит:**
- Токены и ключи API (Telegram, YooKassa)
- Параметры подключения к БД
- ID администраторов и чатов
- Настройки резервного копирования
- Константы проекта

**Принципы:**
- Чувствительные данные читаются из переменных окружения
- Значения по умолчанию для разработки
- Все настройки в одном месте

### 4. db/ - Работа с базой данных

#### db/models.py
SQLAlchemy модели всех таблиц БД. Описание моделей см. в `docs/DATABASE.md`.

#### db/connect.py
Создание engine для подключения к БД.

#### db/handlers.py
Базовые операции с БД:
- `get_user()` - получение пользователя по Telegram ID
- `create_user()` - создание нового пользователя
- `get_autopay_method()` - получение автоплатежа
- `upsert_autopay_method()` - создание/обновление автоплатежа
- `record_payment()` - запись об оплате

### 5. handlers/ - Обработчики событий

#### handlers/start.py
Обработка команды `/start`:
- Регистрация нового пользователя
- Сбор данных (город, телефон)
- Отображение главного меню
- Обработка специальных кодов (реферальные ссылки, быстрые покупки)

#### handlers/callback.py
Обработка всех callback-запросов от inline кнопок:
- Навигация по разделам (О проекте, Города, Подписка и т.д.)
- Покупка продуктов
- Управление подпиской
- Реферальная программа
- Поддержка

**Структура callback_data:**
- `about_project` - информация о проекте
- `subscribe` - раздел подписки
- `buy-subscribe_{months}_{price}` - покупка подписки
- `buy-product_{name}_{price}` - покупка продукта
- `education_catalog` - каталог курсов
- `education_course:{id}` - просмотр курса
- `education_purchase:{id}` - покупка курса
- И другие...

#### handlers/subscription_checker.py
Проверка подписок и отправка уведомлений:
- Проверка активности подписок всех пользователей
- Отправка уведомлений за 3 дня, 1 день и после истечения
- Автоматическое продление подписки через автоплатеж
- Работает в фоновом потоке

#### handlers/db_backup.py
Резервное копирование БД:
- Создание SQL-дампа БД
- Загрузка в Google Drive
- Ручной запуск через команду `/backup`
- Автоматическое резервное копирование (опционально)

### 6. services/ - Бизнес-логика

#### services/payment_service.py
Работа с платежами YooKassa:
- `create_payment()` - создание платежа
- `create_receipt_item()` - создание элемента чека
- `get_payment_status()` - проверка статуса платежа

#### services/referral_service.py
Реферальная система:
- `get_user_referrer()` - получение реферера
- `get_referral_chain()` - получение цепочки рефералов
- `distribute_referral_rewards()` - распределение бонусов

#### services/subscription_service.py
Управление подписками:
- `parse_subscription_duration()` - определение длительности
- `get_subscription_expiry()` - вычисление даты окончания
- `has_active_subscription()` - проверка активности
- `get_subscription_days_left()` - оставшиеся дни
- `format_subscription_remaining()` - форматирование времени

### 7. utils/ - Вспомогательные функции

#### utils/referral.py
Расчеты для реферальной системы:
- `get_ref_level_requirement()` - требуемый уровень для линии
- `get_ref_percent()` - процент бонуса для линии
- `get_ref_inner_percent()` - процент внутреннего баланса

#### utils/media.py
Отправка медиа-файлов:
- `send_media()` - универсальная функция отправки (фото, видео, документы)
- Поддержка локальных файлов и URL

#### utils/text.py
Работа с текстом:
- `escape_html()` - экранирование HTML
- `format_user_mention()` - форматирование упоминания пользователя

## Потоки данных

### Регистрация пользователя

1. Пользователь отправляет `/start`
2. `handlers.start.handler_start()` проверяет, есть ли пользователь в БД
3. Если нет - создается запись в `users` с `has_ended=False`
4. Запрашивается город
5. Запрашивается телефон
6. После ввода телефона `has_ended=True`, отправляется главное меню

### Покупка продукта

1. Пользователь нажимает кнопку покупки
2. `handlers.callback.handler_callback()` обрабатывает callback
3. Создается запись в `pay_metadatas` с `has_payed=False`
4. Через `services.payment_service.create_payment()` создается платеж в YooKassa
5. Пользователю отправляется ссылка на оплату
6. `checker.py` периодически проверяет статус платежа
7. При успешной оплате:
   - Обновляется `pay_metadatas.has_payed=True`
   - Создается запись в `payment_records`
   - Начисляются реферальные бонусы через `services.referral_service`
   - Отправляются уведомления

### Проверка подписки

1. `handlers.subscription_checker` работает в фоновом потоке
2. Каждый час проверяются все пользователи
3. Для каждого вычисляется дата окончания подписки через `services.subscription_service`
4. Если подписка истекает:
   - Отправляются уведомления
   - Если включен автоплатеж - создается автоматический платеж

## Принципы организации кода

### Разделение ответственности

- **handlers/** - обработка событий Telegram, минимальная бизнес-логика
- **services/** - вся бизнес-логика, независимая от Telegram API
- **utils/** - переиспользуемые вспомогательные функции
- **db/** - работа с базой данных

### Обработка ошибок

- Все критические операции обернуты в try-except
- Ошибки логируются, но не прерывают работу бота
- Пользователю отправляются понятные сообщения об ошибках

### Конфигурация

- Все настройки в `config.py`
- Чувствительные данные через переменные окружения
- Значения по умолчанию для разработки

### Расширяемость

- Новые продукты добавляются через обработку в `checker.py`
- Новые разделы - через callback handlers
- Сервисы можно использовать независимо

## Разделы бота

Доступные разделы:
1. **О проекте** - информация о проекте "За любовь"

8. **Стратегические партнеры** - продукты партнеров
9. **Техническая поддержка** - обращение в поддержку

- Покупка подписки на месяц (333₽) или год (3333₽)

## Развертывание

### Требования

- Python 3.8+
- MySQL база данных
- Переменные окружения для чувствительных данных

### Переменные окружения

- `TELEGRAM_BOT_TOKEN` - токен Telegram бота
- `YOOKASSA_SECRET_API` - секретный ключ YooKassa
- `DB_CONNECTION_STRING` - строка подключения к БД
- `GOOGLE_SERVICE_ACCOUNT_FILE` - путь к файлу сервисного аккаунта Google
- `GDRIVE_FOLDER_ID` - ID папки в Google Drive для бэкапов
- `BACKUP_ADMIN_TG_ID` - Telegram ID администратора для команды /backup

### Запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Настроить переменные окружения
3. Запустить бота: `python bot.py`
4. Запустить checker (опционально): `python checker.py` или через uvicorn

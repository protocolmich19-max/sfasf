## 🚀 Запуск проекта

Проект запускается **точно так же**, как раньше:

```bash
python bot.py
```

Для checker (если используется отдельно):
```bash
python checker.py
# или
uvicorn checker:app --host 0.0.0.0 --port 8000
```

## ⚙️ Настройка

Все настройки находятся в `config.py`. Если нужно изменить что-то, редактируйте этот файл.

**Важно:** Если вы используете переменные окружения, они имеют приоритет над значениями в `config.py`.

## ✅ Проверка работоспособности

1. **Проверьте импорт config:**
   ```bash
   python -c "import config; print('OK')"
   ```

2. **Проверьте импорт bot:**
   ```bash
   python -c "from bot import bot; print('OK')"
   ```

3. **Запустите бота и проверьте:**
   - Команда `/start` работает
   - Callback'и обрабатываются
   - Платежи создаются
